О курсе

Курс рассчитан на начинающих. Вы шаг за шагом освоите основы веб‑разработки, научитесь создавать адаптивные сайты, работать с современными инструментами и соберёте собственный сайт‑портфолио.

Чему вы научитесь

  • Создавать семантическую HTML‑разметку
  • Стилизовать страницы с помощью CSS, Flexbox и Grid
  • Добавлять интерактивность с помощью JavaScript
  • Работать с Git и GitHub
  • Собирать проекты с помощью Vite/Webpack

Программа курса

  1. Неделя 1: Введение, установка инструментов
  2. Неделя 2: HTML: структура, теги, формы
  3. Неделя 3: CSS: селекторы, шрифты, сетки
  4. Неделя 4: Flexbox и Grid, адаптивность
  5. Неделя 5: Основы JavaScript
  6. Неделя 6: Работа с DOM и событиями
  7. Неделя 7: Git и GitHub
  8. Неделя 8: Мини‑проект: лендинг
  9. Неделя 9–12: Финальный проект: сайт‑портфолио
